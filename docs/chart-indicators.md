# 图表指标与数值栏

在行情图下方点击当前指标名称，可打开紧凑的指标菜单。默认使用“单项”：一次选择一种，显示在价格主图下方，其他指标不会挤在同一张纵轴上。分时、日K、周K及分钟K均使用相同的选择方式。

菜单里的“同时显示”可选择最多4个副图，上下排列；各副图保留自己的刻度，共用时间轴、光标和K线缩放。再次切换“单项”即可恢复一个副图。设置保存在当前浏览器，旧版成交量／MACD／RSI设置自动兼容。主图的MA、EMA及BOLL仍在右上角图表工具内设置。

## 已实现的25类公开指标

成交量、MACD、KDJ、RSI、BIAS、CCI、WR、ATR、BOLL、EXPMA、ENE、OBV、BBI、BRAR、TRIX、VR、DMI、DPO、DMA、CR、LWR、SKDJ、多空线DKX、MTM、LON。

主图及每个副图上方常驻显示相应颜色、曲线名称、简短中文释义、参数及数值。默认显示最新行情；移动光标后显示对应时间的数据，移出图表后恢复最新值。数值保留两位小数，成交量按股／万股显示；手机上数值栏可横向滑动，不挤压绘图区。

指标使用原始OHLCV计算：切换平滑K线仅改变主图展示价格，不改变指标的计算来源；分时指标先使用已加载的历史分钟数据计算，再映射到当日固定横轴，不在开盘时强行从零重置。缺失或未来分钟留空；周线先聚合原始日线再计算。窗口不足、缺少字段或零分母无法计算时显示“—”，不补造数值。

## 当前数据不支持的项目

参考截图中的所有项目都保留在菜单目录中。依赖额外字段的项目归入折叠的“更多数据指标”，点击会显示原因，**不会切换到虚构曲线**：

- 主买净额、大单净量、大单净额、买卖力道、买卖差、分时DDX等需要真实逐笔或委托数据。
- 主力意愿、散户线、分时博弈、暗盘资金、机构／散户监控、智能参数及九转研判还依赖平台专有分类或未明确的算法。
- 换手率、量比、竞价比值、今昨成交比及逐周期成交额缺少完整历史字段；不能把当前报价的成交额当作历史换手率，也不能用收盘价乘成交量冒充真实成交额。
- 市盈率、市净率、市销率、市现率历史曲线需要对应财务及股本历史，现有K线数据不能推导。

这些条目只是数据能力说明，并非已经接入对应功能。接入真实数据源后才能启用。

计算口径与每个指标的公式、参数、平滑种子及变体见[技术指标公式说明](technical-indicator-formulas.md)。指标基于当前已加载、未复权行情，不保证与东方财富逐值一致；递归和累计指标也受历史长度影响。

## 验证

```bash
node --test tests/*.test.mjs
npm run build
# 另一个终端启动Vite；浏览器脚本拦截API，使用隔离的固定行情，不写服务器数据库。
npm run dev -- --port 8013
node tests/chart_ui.mjs
```

浏览器脚本支持CHART_UI_BASE_URL、CHART_UI_OUTPUT、PLAYWRIGHT_CORE_PATH与CHROME_PATH，默认使用本机8013。涵盖25项切换、分时4副图、恢复单项、数据缺失、菜单缺源说明、设置持久化、光标读数和主题／手机布局。
