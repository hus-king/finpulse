# 20 万元 A 股模拟盘

在主导航进入“模拟盘”，登录自己的 FinPulse 账号即可使用。每个账号独立获得 **20 万元虚拟资金**，与自选股使用相同账号，但选交易股票不会添加自选股或触发新闻、AI 采集。所有成交均为模拟，不连接真实券商。

## 使用

1. 在买卖面板右上角点击搜索按钮，搜索股票名称、六位代码或拼音并选择。
2. 检查报价时间、板块规则、现金及可买／可卖数量。
3. 选择买入或卖出，输入股数，查看预估股款和费用，再确认模拟成交。
4. 资金、持仓与成交记录由后端保存。刷新网页或重启服务后仍可查询。

成功成交后更新账户。若网络中断造成结果未确认，表单会锁定并显示“重试确认成交”；请使用这个按钮，原请求编号不会重复成交。未确认请求保存在当前标签页的账号专属 sessionStorage 中，刷新或离开模拟盘后回来可继续确认；浏览器禁止存储时仅在当前组件内保留。可刷新账户查看成交记录，不能把网络错误当作交易失败后另下同一笔订单。

## 规则

| 项目 | 本版行为 |
| --- | --- |
| 时段 | 已核验交易日北京时间 09:30–11:30、13:00–14:57，结束时间不含；午休、周末、节假日、集合竞价及盘后禁止新成交 |
| 日历 | 使用现有 2026 年交易所休市日历；未经核验的年份显示待更新并暂停成交 |
| T+1 | 当日买入锁定，下一交易日可卖；按买入批次记录，较早的可卖批次优先扣减 |
| 主板、创业板 | 买入 100 股整数倍；卖出不能拆分不足 100 股的零股余额 |
| 科创板 | 正常申报至少 200 股，之后可按 1 股递增；可卖余额不足 200 股时全部卖出 |
| 单笔上限 | 主板 100 万股、创业板 15 万股、科创板 5 万股；同时受现金和可卖数量限制 |
| 佣金 | 模拟双向 0.03%，每笔最低 5 元 |
| 过户费 | 模拟双向 0.001% |
| 印花税 | 模拟卖出 0.05% |
| 不支持 | 融资、卖空、充值、提现、限价挂单、撤单、分红、送股与拆股 |

以上为本产品模拟规则，固定佣金不代表实际券商收费。数量规则参考 [上交所规则](https://www.sse.com.cn/lawandrules/sselawsrules2025/trade/universal/c/c_20260424_10816492.shtml)及[深交所规则](https://docs.static.szse.cn/www/lawrules/rule/trade/current/W020260424690713155663.pdf)。

## 行情与盈亏

成交仅采用服务器有效的未复权 1 分钟报价。分钟日期必须为当前交易日，数据时间不超过 180 秒延迟（结束标签最多领先 60 秒），采集成功时间在过去 90 秒内且没有来源错误。过期、缺失或无效报价暂停成交，不能用昨日收盘价代替。

分钟数据有延迟，不是逐笔行情；本版不模拟真实撮合、流动性、涨跌停排队和滑点。可以手动刷新报价，页面同时按服务建议间隔轮询。

持仓估值使用缓存分钟价格，逐只显示报价时间。缓存不可用时按最近成交价格估算并注明，不把缺失报价记为零元。除选中标的外，其他持仓可能使用较旧缓存，因此总资产和浮动盈亏是估值。

买入费用计入平均持仓成本；卖出净收入减去分摊的成本即已实现盈亏；未卖出部分的估值减剩余成本即浮动盈亏。金额以整数分保存，各项费用单独四舍五入到分；累计盈亏为总资产减初始 20 万元。

## 开发与验证

模拟账户和交易复用 research_records 表，以 owner 隔离。资金和成交在同一数据库事务中写入；SQLite 使用 BEGIN IMMEDIATE，MySQL 使用用户行锁；成功交易按账号与 request_id 幂等，不需要新增 MySQL 表或 DDL 权限。

```bash
NO_PROXY='*' .venv/bin/python -m unittest discover -s tests -v
node --test tests/chart_math.test.mjs tests/paper_math.test.mjs
npm run build
```

Node 的 TypeScript 测试需要支持默认类型剥离的版本（Node 22.18+ 或 24）。浏览器场景使用隔离数据库和受控时钟，不能把测试行情导入服务器数据库：

```bash
NO_PROXY='*' .venv/bin/python tests/paper_ui_server.py --port 8012
# 在另一个终端运行；需要 Playwright Core 与 Chrome
node tests/paper_ui.mjs
```

脚本支持 PAPER_UI_BASE_URL、PAPER_UI_OUTPUT、PLAYWRIGHT_CORE_PATH 和 CHROME_PATH。测试专属时钟控制只存在于 tests/paper_ui_server.py，测试服务只监听本机回环地址。服务退出后删除临时数据库。

实际服务器沿用现有部署与服务；需要手动启动时执行 `sudo systemctl start finpulse.service`，不需要为模拟盘添加定时任务或设置开机启动。部署步骤见[服务器部署与开发流程](服务器部署与开发流程.md)。

发布版本和验证结果见[模拟盘发布记录](superpowers/reports/2026-10-09-paper-trading-release.md)。成交记录每 30 秒随账户刷新回到最近一页，已展开的更早记录需要再次加载；历史记录不会被删除。
