# 新闻分类数据扩充与类别平衡（v32）

本轮继续补数据，未启动训练。关系分类的工作目标是 DIRECT、CONDITIONAL、DISTANT、SENTIMENT、NONE、UNKNOWN 各约 200 条；来源范围任务 COMPANY_EVENT、INDUSTRY_SIGNAL 单独平衡。200 是取样目标，不是给标注模型的答案要求，缺口不能用重复抽样、改 ID 或改标签补齐。

本轮于 11 月 1 日启动、11 月 2 日收尾。已形成 790 道主候选，另有 8 道独立语义审稿开发候选；**尚未达到各类数量基本相同**。全项目按保留旧标签去重后有 3,016 道库存题，旧标签仍需统一口径。结果、差距与两个候选层在下文分别统计。

## 数据来源与复核

已完成 24 次付费快讯查询，取得 9,212 行返回记录，覆盖 2026 年 5—10 月的 12 个分散日期、财联社和华尔街见闻。保留原始响应、请求回执、行号、完整正文及哈希。另从已有缓存选入材料，全部训练候选发布日期限定在 2026-05-01—2026-10-27。

候选按四份不可变清单保存，共 1,271 个新闻焦点—公司配对：

| 候选清单 | 配对数 | 各清单中的来源版本数 |
| --- | ---: | ---: |
| 缓存少数类候选 | 390 | 283 |
| 新日期候选 | 462 | 308 |
| 加工链与跨公司补样 | 338 | 170 |
| 有效正文但业务背景缺证的补样 | 81 | 54 |

合计有 794 个来源 ID、773 个正文与日期组合，覆盖 29 个日期、37 家目标公司。来源版本在清单间可复用，不能将最后一列相加当成独立新闻数。配对也不等于独立事件。根复核逐条验证了 1,271 个配对的正文、标题、时间、焦点和原始响应行绑定；这证明数据是接口返回的内容，不能证明原网站内容真实或事件相互独立。

DeepSeek 做来源事实初标，Qwen 对同一份中性材料盲审；关系阶段另行使用同一份冻结新闻、事实和公司背景分别标注。检索分桶、期望类别、初标答案均不进入盲审输入。旧记录只有在正文、焦点、日期相同且旧来源共识可用时复用；以前请求失败或无共识的相同问题不改 ID 重问。

三批来源共识为 254、381 和 33 个焦点单元，对应 299、552 和 51 个候选配对。格式失败、截断、焦点拒绝、来源事实分歧和业务关系 UNKNOWN 分开保存。13 个 MACRO_SIGNAL 来源事实保留为参考，不改标为两类来源任务中的任一类。

## 少数类的证据与旧数据问题

新增焦煤→焦炭→钢铁、大豆→豆粕→饲料、石化材料和海运价格等机制，并配板块交易情绪及关键暴露缺证的公司对照。使用年报和官方材料中的完整段落、表头、行数据支持加工和目标业务；并列出现两种原料不能充当加工链，行业工艺也不证明某公司是目标的供应商。

23 条机制引文与 4 条官方工艺引文另做来源角色复核。实际公司业务、行业工艺、前景讨论分开记录；4 个未被所选原文支持的地区字段未写入公司背景。豆粕目录保留整行及表头；大商所、上海石化资料仅取得官方 PDF 网页文本提取，记录其文本快照哈希，未冒充已下载验证的 PDF 原文件。

核对旧 v28 的全部 28 条 UNKNOWN 后发现，它们来自 7 个导航、行情、视频说明或残缺表格来源。这些记录在本轮材料质量清单中隔离，旧训练包保持原样。它们不能用来补“新闻可用但关键业务关系缺证”的 UNKNOWN 类。旧库存标签数量与按本轮规则复核后的可用数量必须分别统计。

## 入池与平衡规则

1. 来源事实共识后做事件组审查，旧开发/评估事件、后续进展及其连通组件整体隔离。
2. 两个模型各自输出业务机制；程序按有证据的最短路径生成关系类别。类别相同但材料、终点、中介路径不一致，仍留待审。
3. API 原答和阶段校验结果保留。最终证据校验另记版本；若补绑定，只能绑定同一已引用主体、冻结输入中已有的证据，另存差异，不能改模型材料、路径、条件或类别。
4. 按最终全局事件闭包再次检查，去除重复的事件—公司—焦点—标签及相同模型输入。已知全池标签冲突不能通过只选择其中一条绕过。
5. 仅从明确复核过的候选 ID 无放回取样，每类最多 200；优先增加不同事件组与目标公司。多数类完整原始池保留，少数类不足如实报告。

平衡工具为 `experiments/news_processing/class_balance.py`：`audit_inventory` 输出八类数量、缺口及事件/公司覆盖；`select_balanced(..., reviewed_ids=..., target_per_class=200)` 只生成新的候选子集。它不裁定标签、不认证人工真值、不批准训练。目标值可以调整，但不能把小样本重复次数当成数据量。

## 状态边界

所有输出保持 `human_verified=false`、`independent_test=false`、`training_admitted=false`、`delete_news=false`。旧训练/开发包及 v31 封存的未来评估材料保持不变。付费正文、凭据、运行账本和模型权重不入 Git；生产网站和自动过滤未接入本轮研究。

## 11 月 2 日导出结果：尚未均衡

正式主候选池为 **790 道题**：589 道来源范围题、201 道新闻—公司关系题。按类最多 200 条筛选后为 **524 道候选题**，`target_met=false`。它只是限额子集，不能称为已经均衡的训练集。

| 任务 | 类别 | 本轮主候选池 | 限额后 | 距 200 条缺口 |
| --- | --- | ---: | ---: | ---: |
| 来源 | 公司事件 COMPANY_EVENT | 123 | 123 | 77 |
| 来源 | 行业信号 INDUSTRY_SIGNAL | 466 | 200 | 0 |
| 关系 | 明确一跳 DIRECT | 8 | 8 | 192 |
| 关系 | 条件关联 CONDITIONAL | 0 | 0 | 200 |
| 关系 | 远关联 DISTANT | 7 | 7 | 193 |
| 关系 | 板块情绪 SENTIMENT | 97 | 97 | 103 |
| 关系 | 无支持关联 NONE | 74 | 74 | 126 |
| 关系 | 关键信息不足 UNKNOWN | 15 | 15 | 185 |

来源事实双审共识为 668 个单元／902 个原配对，事件审查后为 618 个单元／843 个原配对（616 个规范焦点、481 个事件组）。后续还要经过关系共识、完整焦点去重和语义复核，所以这些阶段数量不能互相替代。主池覆盖 473 个事件组、596 个规范焦点；事件组数仍不是经过穷尽验证的独立事件数。

主池的 7 条远关联仍全部是铁矿石→钢材→三一／恒立实际投入，包含出口码头预告罢工的潜在供应风险。煤焦、大豆等材料已进入候选，但不能声称它们已通过这份主池的双模型路径准入。大豆路径常见分歧包括审稿模型选错终点、缺引用、材料链与其自己写的关系子类不一致；煤焦链也有物料术语与相邻环节未充分对齐的问题。继续堆原始新闻不会自动解决这些问题。

### 清洗、纠错及复核的区别

- 阶段原答与阶段错误统计保持冻结。完整物料链校验后，只有模型误写在 family 字段的 DIRECT／CONDITIONAL／DISTANT，且程序从证据独立推导的子类与原值完全相同，才做唯一父类枚举规范化。4 条阶段路径因此通过，形成 2 条双模型一致候选；未修产品、节点、条件或判成别类。
- 同一物料链仍须引用和方向一致；无路径的 NONE／UNKNOWN／SENTIMENT 不再因为可选产品字段的空串或同义表述不同而自动失去共识。这些差词记录另做语义复核，不能仅凭类名相同入池。
- 最终共有 64 个唯一语义审稿决定，53 KEEP／11 PENDING；部分 PENDING 本来就未成为可导出候选。审稿分别检查固定焦点、完整标题和正文、目标主营、加工方向及公司数据口径。2 个根复核覆盖均有原意见、证据和显式 resolution；不是按文件顺序覆盖 hold。
- 标签本身必须可由给定资料独立支持；原回答里未被采用的旁句仍保留并注明，不能拿来训练理由生成。例如光伏概念反弹与真实逆变器主营足以支持 SENTIMENT，但不认证原解释附带的采购否定；另一公司的采购均价不能认证目标公司的采购价。

### 补做的 8 组独立语义对照

本轮发现条件类仍为 0 后，另行预先声明 8 组开发对照；两名审稿代理使用全新上下文，只看相同冻结新闻、公司和行业原文，不看原老师标签、错误或彼此意见。结果同类一致：**条件关联 2、远关联 4、无支持关联 2**。这是标注一致性，**不是 8/8 准确率，也不是独立测试**；两名审稿代理属于同一模型家族，不冒称为两个独立模型。

这 8 组共享 4 个新闻单元、6 家公司，其中 5 个配对已有原老师结果，3 个是新增公司对照。它们单独存为 AI 语义复核开发候选及原生格式，不混入前述主池；核对后与主池没有相同模型输入重复或标签冲突。

| 固定消息 | 目标 | 两名独立 AI 审稿的标签 | 关键边界 |
| --- | --- | --- | --- |
| 焦煤期货报价 | 恒立液压 | DISTANT | 焦煤→焦炭→钢铁／钢材→实际钢材投入，传导未确认 |
| 焦煤期货报价 | 华鲁恒升 | CONDITIONAL | 实际煤炭投入有证据，是否适用焦煤这一煤种未确认 |
| 焦煤期货报价 | 恒瑞医药 | NONE | 未给能连接该焦点的具体业务通道，不能泛补能源采购 |
| 大豆市场报价 | 牧原股份 | DISTANT | 大豆→豆粕→实际饲料原料投入；有官方加工定义 |
| 大豆市场报价 | 恒瑞医药 | NONE | 不能仅凭企业经营就猜有大豆／饲料原料暴露 |
| 电池级碳酸锂报价 | 紫金矿业 | CONDITIONAL | 锂业务与当量产出有证据，实物电池级品种仍未证明 |
| 神华煤炭销量 | 华鲁恒升、梅花生物 | DISTANT，开发边界候选 | 需要额外市场量价／可得性传导，不能把单家销量当全市场供给；仍需进一步证据确认 |

这一步说明“本轮主池没有条件类”不能直接解释为素材里没有条件关联。旧老师、词面门控与语义审稿对品种粒度、统计指标和跨主体市场传导存在口径差异。下一轮应先将这些边界和更正标签单列、扩成不同机制的对照，再统一训练口径；不能只为了配额把待审条目改类。

### 全量库存与本轮审定数量分开

保留旧 v28 标签、v31 增量及本轮两个候选层，排除 28 条旧坏材料后，共有 3,089 个输入记录；按完全相同的模型输入去重 73 条，剩 **3,016 道标签库存题**，没有发现完全相同输入的标签冲突。旧标签尚未按本轮规范逐条重审，这个库存不等于统一口径的已批准训练集。

| 关系类 | 全量保留标签库存，非本轮统一审定 |
| --- | ---: |
| DIRECT | 63 |
| CONDITIONAL | 152 |
| DISTANT | 76 |
| SENTIMENT | 163 |
| NONE | 1,336 |
| UNKNOWN | 15 |

因此整个项目不是只有本轮条件类 0 条；旧条件标签仍有库存，需要统一“暴露尚未确认”与“影响幅度尚未实现”的口径。真正缺口包括可靠 UNKNOWN、不同机制的远关联和明确一跳正例，多数 NONE 应保留在原池并在训练取样时限量。未达到“各类数量基本相同”，本轮没有为此启动训练或制造重复样本。
