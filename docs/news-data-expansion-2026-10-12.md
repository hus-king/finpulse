# 真实新闻配对扩充：首次采集与 DeepSeek 小批标注

已建立可复跑的来源采集、三任务弱标注和全量复核队列，完成第一批实际采集和标注。**没有重训、没有接入线上过滤，也没有建立新的独立测试结果。** 300 个不同真实事件与约 1,200 对的目标尚未达到：这批只有 205 份来源文档，保守归为 76 个待复核家族，不能把公告数或公司对数当作独立事件数。

## 实际材料

价格、生产量、行业产出及公告覆盖更多新闻主题，但目标公司背景仍只有三一重工、中远海控、牧原股份、恒瑞医药、浪潮信息、三安光电、新华保险。每篇四家公司是确定性轮转对照，**不保证包含该新闻最有代表性的受影响公司或同业困难负例**。12 个检索词、八页 NBS 列表及一个 MIIT 列表只找到这 205 份候选；没有放宽窗口或追加检索来凑数。

实际抓取时间单独记录为 `first_seen_at`，不以历史公告日期冒充历史可用时刻。HTML 日期冲突保持待核验。查询和下载结果均保存请求及响应元数据，失败缓存视作本次观察的失败，不暗中重取替换原件。后续重试须另行声明。

有 11 份来源此前已在 v6/v7 出现过，共 44 对，记录在 `prior_source_exposure.json`；它们不成为新独立材料。此检查在小批标注启动后补做，不能宣称预先按新旧曝光分层抽样。其余来源也没有经过事件层面独立性人工确认。保守家族按发行人/公告类型或统计发布时间合并，精确正文副本传递合并整家族；同一项目的不同标题、跨日期更新和转载还要补人工分组。哈希分配的 train/validation/calibration 是待核验的开发角色，**不能直接与旧开发角色混合训练**。

## 新任务与实际标注

本批新增独立模块 `experiments.news_processing.expansion`，不修改旧版两个任务、旧参考或固定模型。分开输出：

1. `own_event`：目标公司自身事件及其新闻归属引用。
2. `external_signal` / `signal_kind`：外部信号及原文依据。
3. `transmission`：到具体业务的直接、条件、较远、情绪、无连接或未知关系；条件/较远关系必须列缺失条件。

外部信号没有自动成为目标公司的自身事件；纯自身事件无外部信号时不能填写行业传导。当前 v1 的“对目标公司而言的外部信号”仍有边界问题：行业运行材料中的信号存在性和目标业务适用性可能被混为一谈；价格统计又可能被解释为投入成本或产品定价。应在下一版明确定义新闻层面信号与目标业务适用性、价格信号类型和事件阶段，再另行冻结新任务材料。**本轮标签不因此被追改，也不直接导出为旧模型训练标签。**

正文初步可用材料中按既定次序选择 24 份、96 对进行小批试验。构成是 18 份公告、4 份 MIIT、2 份 NBS；不是各传导机制的平衡样本。DeepSeek 使用既有 PPIO 配置 `deepseek/deepseek-v4.1-flash`，主提示与复核提示来自同一提供方，均为弱标签。

实际 48 次请求、282,802 个观测 token；冻结上限 100 次尝试、700,000 token 软停止、三并发。输入/提示/端点/模型绑定缓存，持久请求预留保留中断成本。两次真实恢复验证均没有增加调用或 token；无效答案保留待复核，不隐式付费重标。

## 独立调用与复核界面

Copilot 完成流程及代码审阅。已检查其建议：Journal 内部确有互斥锁，因此不采纳假设的并发数据丢失结论；保留无效缓存、显式覆盖统计，补原件摘要检查、来源解析回归、整家族合并和原子原件写入。首次采集暴露空正文摘要被错误合并及当前 NBS 容器不匹配，失败记录保留，添加先失败后通过的回归后在任何标注前完成重放。

按来源确定性选出的 6 对盲包不含 teacher 答案。Gemini `gemini-3.8-flash-medium` 超时，没有形成参考。一次 Copilot `auto` 回退返回六对；原答有终端折行，原件保留，仅恢复 JSON 字符串中的未转义换行，不改变标签。四对通过字面结构检查，两对失败；还发现对业绩说明会材料的解释串入锂电池内容，以及成本/产品定价边界。**这些独立调用只作诊断，未进入参考或改写本轮指标；后端独立性未证明，全部 `human_verified=false`。**

全量复核页面保留 820 对，可按状态、公司或标题筛选，查看主/复核提示、正文、表格、业务背景及原始来源。实际浏览器验证：820 行可显示、五条分歧筛选正确、点击可打开完整原文。队列为 436 待来源、288 尚未完成双提示、52 标签/引用校验失败、5 分歧、39 弱一致待语义复核。没有人工金标，没有自动删除，也没有自动训练准入。

最终完整后端 388 项测试通过，26 项为新增覆盖。保留现有 Starlette/httpx 弃用警告。旧 v7 归档清单的 196 个文件逐一校验均未变化；旧模型及前瞻目录未写入。

## 运行与归档

可选采集依赖与生产服务分开安装：

```sh
uv pip install --python ../finpulse/.venv/bin/python -r experiments/news_processing/requirements-data.txt
../finpulse/.venv/bin/python -m experiments.news_processing.expansion_sources \
  --root .runtime/NEW_DECLARED_BATCH --profiles PATH_TO_SOURCE_BACKED_PROFILES --limit 300
../finpulse/.venv/bin/python -m experiments.news_processing.expansion \
  --root .runtime/NEW_DECLARED_BATCH --config PATH_TO_PRIVATE_CONFIG
../finpulse/.venv/bin/python -m experiments.news_processing.expansion \
  --root .runtime/NEW_DECLARED_BATCH --review
```

采集根目录冻结后拒绝重新采集。标注恢复不需要重新导入，不改冻结文件。新增公司必须提供巨潮发行机构标识及来源支持的背景，不能仅填写股票代码猜查询身份。原始材料、弱标签和 HTML 保留在 `.runtime/news-expansion-v8-20261012/`，不将 API 配置或全文材料提交 Git。

下一步先修正必填字段和引用生成，明确外部信号/公司适用性及投入成本/产品价格边界，补同行业公司及资格/地区困难对照；复核来源和重复事件后再扩到 300 个已确认事件。公开 DuEE-fin/FinQA、FinRE、CFLEB FinNSP/FinNL 仍作为辅助任务候选，**本批没有下载或导入它们**，不能把事件问答或负面主体标签直接映射为行业传导；DuEE-fin 与 FinQA 的派生重叠也须分组隔离。独立测试另行预先声明，旧 v6 前瞻协议和 C 不自动删除的约束保持。
