# PEG B 模拟盘策略

2026-10-29 上线。策略 ID `official-peg-buffered-v1`，规则版本 `peg-b-3x9-stop12-band5-v1`。原 `official-low-peg-v1` 的前5策略保留，新方案不改变 PEG 公式、合格门槛或已保存的榜单。

## 固定持仓规则

- 合并合格金融、非金融股票，正前瞻 PEG 升序、同值按代码排序。使用今日零点前已发布且覆盖上一完整交易日的300股快照；缺失、过期或版本不符时保留持仓等待。
- 扣除挂起的价格退出和冷却股票，每个申万一级行业最多5股进入约束排序。持仓在此排序前9内保留；空缺从前9中补齐。最多3股，每一级行业最多1股，行业资金不超过权益60%。行情导致暂时超限时减仓，受阻部分保持真实持仓。
- 固定3个资金名额，每份 `(权益－0.4%权益－30元)/3`，再按板块申报单位取整；余额不因可成交性顺延改选其他股票。目标总仓为100%，不融资。
- 单只当前市值与目标相差不超过账户权益的5个百分点且行业资金未超限时免微调；必要退出和新建仓不受该区间阻挡。卖出受阻、T+1锁定的股票继续占名额。
- 前一交易日复权收盘价跌至首次实际建仓对应复权价的88%及以下时，锁存退出指令。加仓、减仓、切回手动或重启不重置该锚点；全部实际卖出后才开始10个完整交易日的冷却。
- 此策略不使用旧方案的账户回撤15%自动暂停；保留手动接管、账户停用、版本检查、有效报价、T+1、费用与现金校验。

## 日内运行与账本

10:00生成并持久化决策，只用不晚于10:00的分钟报价作目标测算。10:02（含）至10:06（不含）执行卖出；10:07（含）至10:11（不含）基于实际剩余持仓产生并执行买入。错过窗口不追溯成交，次日重新评估。原持有5股的账户允许在T+1约束下分日减至3股，不重置资金或成交历史。

决策、阶段结果和固定请求编号在重启后恢复。成交重放先于窗口检查；不会重复扣款或重置建仓锚点。建仓锚点、退出挂起状态和冷却日期与成交在同一事务中更新；写入失败一起回滚。首次启用从完整不可变成交账本恢复连续持仓的第一笔买入价，账本数量不符时拒绝启用。显式账户重置会归档并清除该策略状态。

止损使用每次重新取得的同一复权参照，把原始建仓日OHLC与执行价映射到当前前复权基准；支持腾讯日线的仿射调整。持仓超过普通230天日线缓存时按原建仓日补齐历史。参照不完整或不能明确拟合时等待核验，不偷偷改用平均成本或把锚点归零。

`backend/quant/sw_industries.json` 来源于研究档案 `peg-history-2018-2026-20261028/industry` 的564股申万一级行业生效区间，观察日2026-10-28；决策保存分类文件摘要与日期。不会把榜单的二级行业冒充一级行业。新成分股或行业变更需更新该资料，未知分类会暂停计划并显示原因。

## 回测参考与执行差异

冻结研究位于 Stock-Analyzer 的 `outputs/peg-execution-20261029/`。严格时间口径2022-05-05至2026-08-31：B累计收益112.2767%、年化19.76%、日终最大回撤20.0638%，平均仓位96.09%。这段历史已参与研究，不是未使用测试集；2018起补充口径仍出现43.37%回撤，20.06%不是未来回撤上限。

线上持仓规则沿用B，但执行仍使用现有模拟盘的有效分钟报价整笔成交与费用，尚无分钟成交量1%参与率、部分成交、按委托累计最低佣金、20bp摩擦成本下限，也未完整实现研究中的分红应收/红股上市/合并转换。最近公司行动或复权变化待核验时暂停相关股票成交。因此不能把112.28%直接视为线上相同引擎的预期收益。上线后需要另行累计前瞻业绩。

## 后续榜单比较

固定上述B持仓与研究成交引擎、相同历史时点数据和成本，重新比较纯PEG与少量替代排名。先做单因素、去极值和简单权重方案，纯PEG必须作为候选；再视跨时期稳定性决定是否训练模型。按时间滚动选择和验证，保留数据发布日期与标签成熟期隔离，不在最终测试期反复选参数。以组合扣费收益、回撤、换手和不同起点稳定性评价，不能用单股涨跌预测准确率代替策略效果。新排名只有通过固定执行器验证才考虑替换正式榜单。
