# 事件新闻清洗、交易时段与近期先验：第二版离线预测器

本版本仍以收盘完整日线为条件，预测未来第3个市场交易日未复权收盘价相对当日收盘价的方向。它不是开盘预测器，也不是按当日收盘价成交的策略。公司与新闻编码器为冻结的 Qwen3-Embedding-0.6B；下游投影、注意力和GRU接受监督训练。

## 新闻准入与审计

`scripts.prepare_direction_corpus` 在原始快照之外生成独立模型视图。原始正文不覆盖；`cleaning-audit.json` 记录源ID、来源链接、分类、排除原因、事件原文依据和删除的行情句。

- 纯股价、成交及资金流描述不进入新闻向量。
- 商品价格、产品销量、供需、原材料等信息不能因为含“涨跌”而被当作股价描述。
- 同时含有行情与事件的文章保留事件和上下文，只删除能识别且不含事件、解释或风险条件的行情句；同时含事件和股价的句子保留原文，不自动改写因果关系。
- 付费墙、已知非新闻页面、清洗后过短文本和无法明确识别事件的材料隔离。后者标为`review`，不会默认当作事件训练。
- 正文与日期仍需满足原有`extracted_body + body_verified`要求；同URL版本和转载去重继续执行。

分类为规则原型，不等于经过独立人工标注验证的语义分类器。它可能漏掉未覆盖的事件，也可能将历史背景误识别为事件。事件级首次披露及语义转载去重尚未完整解决。审计抽查不能解释成整批数据的精确率。

被排除的文章版本仍作为版本选择的“墓碑”保留：先选择截止时可获得的最新版本，再判断是否排除，避免新版被排除后旧版重新进入样本。

## 时间处理

1. 发布时间优先从正文头部恢复，必须与已核验发布日期一致。没有明确时分时，可用性保守记到当日23:59:59；只知道分钟时取该分钟最后一秒。日期不精确的新闻时段标为未知，不能因这个可用性边界被误标为盘后；计算衰减时采用该日零点对应的最老可能年龄。不能把搜索接口的日期默认当成当天零点可获得。
2. 严格口径可获得时间为`max(发布时间, 实际观察时间)`。按这个时间归入首个可使用的收盘样本；晚采旧文不能倒填到过去的日序列。
3. 新鲜度仍由原发布时间计算，晚采集不能刷新事件年龄。另提供实际可获得年龄，区分事件老化与数据迟到。
4. 新闻特征包括发布时间年龄、时间不精确标记、可获得年龄、盘前/上午/下午/非交易时段标记、交易时长年龄。一天内仍采用集合汇总，不建模逐条新闻的日内先后依赖。
5. 交易时长按9:30—11:30、13:00—15:00累计。夜间、午休和共享行情日历中的休市日期不累计交易时长。例如周五收盘后与周一盘前新闻，到周一收盘均只有一个交易日的市场反应机会；自然时间年龄仍有区别。
6. 每日量价只使用该日收盘及以前数据；训练与验证、验证与测试之间清除跨边界的3日标签。标准化只在训练集拟合。

`publication_replay`按发布时间回放后来获取的新闻，只能作为探索。它不会将公司事实的可获得时间倒填到过去，也不构成历史时点可用数据的证明。行情快照仍可能包含源修订，本轮不声称具备历史逐时点行情档案。

## 近期先验

保留32维文本投影、每日新闻注意力、32维GRU和时间注意力，新增两个明确的先验：

```text
新闻衰减 = exp(-ln(2) × 自发布以来的交易时长 / 半衰期)
每日新闻 = Σ(新闻注意力 × 新闻衰减 × 公司融合后的新闻表示)
时间注意力logit = 学习的logit - ln(2) × 日状态距截止日的交易日数 / 半衰期
```

新闻衰减在softmax之外乘到正文表示，因此一天只有一篇新闻时也不会被归一化抵消。空新闻选项不作年龄衰减。时间注意力作用于已经累积历史的GRU状态，其权重不能解释成单日新闻的独立因果贡献。

固定比较无近期先验、1交易日半衰期、3交易日半衰期；其余网络、输入和训练超参数一致。先验表达默认偏好，不保证新新闻比重大旧事件更有用，也不保证最终预测对新闻年龄单调。

若训练集没有任何新闻与公司资料同时可用的样本，预先规定禁用公司输入，并记录到清单，避免拿测试期才可用的公司事实运行一个从未学过该输入的模块。

## 长正文和行情

新闻使用`--chunk-long-texts`：每块最多1024 token，重复公司/代码/标题，正文最多重叠64 token，覆盖全部正文。每块末个有效token池化并归一化，再按新增正文token数加权平均并归一化为1024维文章向量。这避免尾部直接截断，但汇总仍会压缩信息，尚未验证其相对其他长文编码方式的增益。

训练行情使用每只股票同一批次的新抓完整序列，避免手/股混拼。实际检查的部署端AkShare适配器将`sz000*`排除在成交量乘100的分支之外，误把这些股票按指数处理；准备脚本对这批股票补乘100。其他股票沿用该适配器已统一的股数；原始响应、转换倍数和文件指纹保留。要求未复权与前复权参考同时存在，剔除无法完成除权检查的窗口。

## 训练与复现

先用现有只读导出、历史补采脚本生成原始快照；新抓历史新闻保留真实获取时间。准备输出和训练输出目录必须不存在。

```bash
python -m scripts.prepare_direction_corpus \
  --source collection/corpus.json --market-dir collection/market \
  --signal-start 2026-04-27 --output prepared

python -m scripts.embed_direction_news \
  --corpus prepared/corpus.json --model /path/to/Qwen3-Embedding-0.6B \
  --output prepared/embeddings.npz --chunk-long-texts

python -m scripts.embed_company_facts \
  --facts company-facts.json --model /path/to/Qwen3-Embedding-0.6B --output company

python -m scripts.train_attention_direction train --recency \
  --corpus prepared/corpus.json --news-embeddings prepared/embeddings.npz \
  --company-dir company --output run-01

python -m scripts.train_attention_direction predict \
  --corpus prepared/corpus.json --news-embeddings prepared/embeddings.npz \
  --company-dir company --artifacts run-01/observed --output latest_predictions.json

python -m unittest tests.test_news_direction tests.test_attention_direction \
  tests.test_direction_backfill tests.test_direction_recency -v
```

候选为量价逻辑回归、新闻逻辑回归、原融合GRU、时段注意力、1日和3日半衰期注意力。训练前保存语料、编码设置、源码指纹、种子、候选和超参数。正常划分按验证BCE早停，按验证平衡准确率、再按log loss选择；之后才计算测试指标。严格数据无法三段划分时，固定30轮、预先指定3日半衰期模型，只作为小样本流程演示。

每份权重保存后重新加载并逐条核对测试预测；预测核对模型文件SHA256、向量ID、公司卡快照、编码设置及数据策略。当前完整注意力预测仍绑定本轮向量集合，没有实现线上新文章的增量接入。输出为`research_only`，不接入交易和网页服务。
