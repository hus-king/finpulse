## 模型与输入

完整模型使用冻结的472个新闻向量和84张主营原文卡；每张卡与新闻均为1024维，投影至32维。新闻查询公司卡，门控融合后按日注意力汇总；与每日量价/时间特征一起输入单层32维GRU，再对全部历史隐藏状态做时间注意力。完整网络49,363个可训练参数，原GRU39,905个。公司卡来自23只股票的46个可确认历史快照，只有主营概述及逐字片段，没有假造财务或供应链数据。

公司事实在两个新闻口径下都遵守实际known_at，不使用当前公司介绍回填历史。公司业务数据的原始公开日期未知，只有缓存可确认时间。编码使用GPU，分类器使用CPU，种子42；公司卡编码约2.06秒，没有截断；新闻沿用本轮冻结缓存，其中292份正文受1024 token上限截断。

原GRU与新架构之间同时改变了每日新闻聚合、每日量价序列、时间特征及注意力，因此比较不能隔离某一个注意力层的贡献。两个新候选通过是否屏蔽公司卡进行背景消融。

## 按实际可获得时间：固定参数流程演示

共145个股票日样本、7个信号日期，115个样本带新闻。清除63个跨边界标签后，训练为2026-10-08至10-09的42个样本；测试为10-15至10-16的40个样本，标签最晚截至10-21。没有验证集，预先固定30轮并指定完整模型为演示候选，不依据测试表现改选或调参。

训练集22/42个样本带新闻，只有4/42个样本有当时已知的公司背景；测试集37/40个样本带新闻且有公司背景。公司信息覆盖变化很大，不能把结果直接解释为公司信息有用或无用。

## 按发布日期：探索回放

共2533个股票日样本、134个信号日期，其中349个样本带新闻。按时间60%/20%/20%划分并清除118个跨边界样本后，训练1388、验证450、测试577。训练仅44个样本带新闻，验证仅6个，测试294个；训练及验证均没有当时已知的公司主营背景，测试有97个。公司模块在这一口径下缺少训练监督，无法用它评估背景融合的泛化能力。

最多200轮，验证logit BCE早停、patience 25。原GRU最佳第7轮，两个注意力候选最佳第1轮；完整训练继续至早停条件满足后恢复最佳状态。测试前按验证指标选中的候选是无公司卡的分层注意力GRU。
