FinPulse 网页的 Android 安装版，支持 Android 8.0 及以上，无 CPU 架构限制。

下载下方 **FinPulse-v1.0.0.apk**，允许浏览器/文件管理器「安装未知应用」后安装。

- 与服务器网页共用账号、行情、新闻和研究记录，网页功能更新后无需重新安装 APK。
- 默认连接校园入口 `http://202.114.212.116:8000/`，需要手机所在网络能够访问该服务器。
- 顶部「服务器」可切换 Tailscale 入口（需先连接 Tailscale）或填写自定义 HTTP(S) 地址。
- 当前公网域名 `http://airhust.cn:16800/` 返回 403；安装 APK 不会改变服务器的网络可达范围。
- 支持返回键、刷新、登录会话保持、JSON 文件导入及 JSON/CSV 导出。文件由 Android 系统选择器读取或保存，无需申请存储权限。
- 这是联网网页客户端，后端不在手机内运行。现有 HTTP 入口未加密，请仅在可信网络使用；部署 HTTPS 后可直接切换。

APK 使用专用 release 密钥签名；校验文件见 `SHA256SUMS.txt`。不包含服务器密钥或数据库文件。
