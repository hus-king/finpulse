# 首批来源支持的新闻训练候选数据

本轮实际交付 **141 条标准 messages JSONL 候选**：121 条事实整理、20 条单事件—公司关系。另有 27 条排除/待审记录。原始资料、初标、修订、语义审稿及排除原因均可追溯。数据为 AI 银标候选，人工确认集仍为 0；未重训、未接入线上、未启用自动过滤。

仍是原有 8 篇新闻、9 家公司，**141 条不是 141 篇独立新闻**。50 条事实来自同一张价格表，事实与关系任务也有共同来源。输出统一为 `development`；原来的 train/calibration 角色保存在 `parent_split`，仅供溯源，没有重新制造独立测试集。

事实类别为公司事件 16、行业信号 105；时间角色为当前 3、持续/统计期间 107、计划 10、历史 1。关系候选分布为自身事件 OWN 3、明确单事件无连接 NONE 14、条件传导 2、直接传导 1。较远传导等边界仍有分歧，未用强行改标来补类别；这批数据存在明显的类别和来源集中，不能代表全市场覆盖或模型准确率。

## 本次处理

1. 价格表按原始 HTML 单元格逐行核对：121 行全部按序对应，包括 50 条价格、表头、单位、比较期、附注及规格说明。形成 7 个有界价格块；数值直接解析，避免长 JSON 截断。涨跌为零仍保留原始 FLAT，不虚构价格变化。
2. 时间候选保留原文字符坐标、精度、证据编号和可证明的日期。明确年份/月份/统计区间及相对时间不补造具体日；AI 选择候选与角色。标题中的期间与事件的具体时点分开处理，不用落款日期代替签约或付款日期。
3. 将“自身事件”作为 OWN，与外部传导分开。关系样本限定一个明确事件；NONE 不表示整篇新闻都无关。保留具体产品、原料、上下游及地区背景。
4. 模型文件只保留标准 messages、样本编号及溯源字段，不嵌入审稿意见或重复的 input/target。审稿理由和标签留在单独审计文件。导出时重新校验原答、候选及来源，而不是信任保存的“有效”标记。

事实任务是**给定事实证据片段的结构整理**，不是整篇新闻穷尽抽取；关系任务是给定事件及业务背景的分类。这批材料尚不能验证端到端新闻处理能力。

## 审稿过程与遗留问题

先执行 Codex 来源整理与逐条复核，再与独立 Copilot 审稿对照；只有字段和证据校验通过、核心标签一致且没有未知项的样本进入银标候选。Codex 是数据整理者，其复核不冒充第三方独立审稿或人工确认；Copilot 请求模型为 auto，实际服务模型未核实。

原定 Gemini 审稿的 6 批调用均因 Antigravity 账号所在地区不支持而失败，未重试或绕过限制。保留失败记录并明确改为上述两种复核角色。新增 DeepSeek API 调用为 0，原共享账本仍为 210,019 个报告 token；CLI 额度未计量。

27 个待审条目包括 18 个标签分歧、9 个不确定/证据检查失败。例如：

- 药品获批与历史原研背景的主体、阶段及日期；许可已签署与权利未来生效的区别。
- 普通中板与三一实际钢材品种暴露、汽油市场价与中国石油实现售价的传递条件。
- 95号汽油是否对应工程机械、养殖运输或航运的实际燃料；未证明时不标投入成本。
- 造船完工到航运运力/运价、锂电产量到充电需求的多步链条。

没有将分歧率解释为准确率，也没有把排除项解释为“不重要新闻”。人工发布文件保持空，不能由 AI 自动代签。
