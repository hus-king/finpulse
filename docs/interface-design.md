# FinPulse 界面设计

2026-10-27。行情、热点、PEG、模拟盘、早报和连接状态共用同一套研究工作台外观。

## 视觉规则

- 夜间：`#090c12` 背景、`#0d131e` 面板、`#16213a` 次级层。正文 `#dce3ef`、标题 `#f6f8ff`，不通过压低文字亮度营造深色。钴蓝 `#3375ff` 用于曲线，`#0b2050` 用于选中背景的渐变；助手使用 `#280f4c` 紫色渐变及 `#ae7ced` 紫色细节。红 `#e34a60`、绿 `#16ab83` 保留清晰色相。
- 日间：`#f4f3ef` 暖白背景、`#fcfbf8` 面板、`#eeede9` 次级层。保留同样的边线、布局和信息层级。
- A 股红涨绿跌及利好利空语义保持一致。中性色承担结构，颜色承担状态。
- 图表与交互控件使用 1px 边线、2px 圆角；新闻与侧栏以留白、文字和细线分段。已完成的流程状态不再常驻，采集限制和技术说明按需展开。
- 桌面正文最大宽度 1840px，边距 24–56px，模块间距 22–34px。窄屏将行情与研判改为纵向布局，宽表在自身区域内横向滚动。
- 同一色相按底层、细线、文字、透明渐变区分角色；不把完成状态、采集说明和每个容器都染成实色。所有颜色入口在 `src/terminal.css`；`--theme-*` 供组件使用，`--chart-*` 供 ECharts 使用。样式在已有组件样式之后加载。
- 字标使用定制切角的 F、P 与几何字形轮廓，F 的上端加入小面积蓝紫渐变。图形为本地 SVG，其他字形基于 Space Grotesk 转为轮廓，不依赖运行时字体下载；许可见 `docs/brand-font-license.txt`。站点图标使用同一 F。

参考来自用户提供的 [ArtCraft](https://getartcraft.com/)、[AIRHUST](http://airhust.cn:12000/) 和 [TradingView](https://www.tradingview.com/)，以及 [IBM Carbon 的配色分层与深浅主题指南](https://www.carbondesignsystem.com/building-blocks/foundations/color/guidelines)。这些参考用于设计研究，不构成产品功能依赖。

## 动效与交互

- 页面切换使用 500ms 淡入及 9px 位移；屏外面板进入视区时使用 550ms 淡入及 14px 位移。
- 按钮反馈为 160ms；实际报价发生变化时短暂高亮 700ms，不插值或编造中间价格。
- 分时和情绪走势使用从曲线向背景消退的轻渐变；行情图表保留原始数据时序和空缺。
- 桌面精细指针设备（1024px 起）显示右侧阅读刻度。按 [ArtCraft](https://getartcraft.com/) 发布的 ruler 布局和运动参数重写：60px 刻度栏，顶部 48px + 12px 留白；每 1% 一条刻度、每 5% 标数。默认按文档像素长度随页面移动，悬停 150ms 后以阻尼 10 压缩为全页地图；松开后逆向恢复。显示当前视窗范围、3px 鼠标预览线，点击按指数缓出跳转，拖动按 0.18 阻尼定位。
- 百分比紧贴指针，使用 9px 等宽三位数字及 280ms 逐位滚动，没有边框、底色或阴影。指针在前 3% 淡入，靠近底部时读数移到指针上方。刻度随滚动速度伸长；章节按 34/20/16px 在顶部、竖排、队列及地图间逐字移动，悬停提亮、点击 350ms 短暂染色。中文密集锚点在地图中避让；页面为导航标题预留侧边空间。
- “我的自选”在桌面限制为视窗高度并吸附顶部，只有列表内部滚动；标题、操作按钮及底部管理入口保持可见。滚轮到列表边界也不会带动主页面。窄屏列表保留最大 60dvh 的内部滚动区域。
- 消息评分仪表与分数、时间加权说明保持同一中线；红绿弧线使用 6 个 SVG 单位，指针 2.5 个单位，避免限宽后的图形靠左及细线难辨。
- `prefers-reduced-motion: reduce` 关闭动画、过渡和平滑滚动。键盘可跳至主内容，控件保留可见焦点。
- JS 不运行时内容仍然可见；只有屏外且已被观察的面板才暂时进入待展示状态。

## 请求错误修复

旧 `api()` 把 `response.json()` 的全部异常转换成 `null`。如果请求在收到响应头之后、读取正文过程中被取消，`AbortError` 会被误报成「接口返回格式异常」。React StrictMode 的清理、切换股票及请求取消时机均可能触发这条路径。

现在保留取消原因，调用方继续按取消请求处理；响应读完后也再次检查取消状态。请求声明接受 JSON 并绕过浏览器缓存。真实的空响应、HTML 响应和无效 JSON 使用不同错误码，并指出接口路径，不显示查询参数或响应正文。HTTP 状态、登录事件及 CSRF 保持原有处理，不自动重试写请求。

该缺陷已通过可控取消场景复现并覆盖。检查时服务器公开行情、健康及情绪接口返回正常 JSON；仅凭用户截图不能排除其浏览器或代理曾返回其他内容，因此没有将代理问题认定为已证实原因。

## 验证

```bash
npm run build
node --experimental-transform-types --test tests/*.test.mjs
```

验证范围包括 API 取消、HTML/空响应、HTTP/鉴权事件、CSRF、不重试写请求，以及已有图表计算和缓存测试。界面另行检查深浅模式、桌面/手机布局、图表工具、导航、搜索弹窗及阅读进度。

本地需要直接使用服务器公开 API 预览时，可在被忽略的 `.env.local` 设置 `FINPULSE_API_TARGET`。不设置时仍代理到本机 8000；该变量仅供 Vite 开发代理使用，不进入生产前端。
